## Histórias de Usuário

### HU01, Gerenciar Conta
Como cliente, eu quero gerenciar a minha conta para ter acesso as minhas informações e para que possa ter acesso as outras funcionalidades do sistema.

### HU02, Efetuar pedido
Como cliente, eu quero efetuar um pedido de aluguel de carro para poder utilizar um carro por um determinado período.
 - o cliente precisa estar logado no sistema

### HU03, Modificar pedido
Como cliente, eu quero modificar um pedido de aluguel de carro para poder alterar as minhas escolhas, caso mude de ideia.
 - o pedido precisa estar previamente cadastro no sistema no sistema
 - o pedido precisa não ter sido avaliado por algum agente

### HU04, Consultar pedido
Como cliente, eu quero cunsultar um pedido de aluguel de carro para poder saber em que situação o pedido está.

### HU05, Excluir pedido
Como cliente, eu quero excluir um pedido de aluguel de carro para poder retirar o meu pedido, independento do motivo.
